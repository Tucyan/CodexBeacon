# 方案 A 正式实现

需求：采用五个基础颜色，提供四个深色、四个浅色预设。

## 实现计划

1. 新增输入区背景、次要文字两个颜色；保留背景、正文、强调色及两项透明度。旧 JSON 按原有颜色派生新字段，保留用户内容、布局及原三色。
2. 前端集中定义八个预设，设置中按深浅分组，可一键应用或逐项微调；选预设只改变五个颜色，保留透明度。
3. 边框由背景与正文混色生成；按钮继承强调色，按钮文字自动选择更高对比的黑/白色。输入框、占位提示、次要信息使用各自颜色；额度进度条填充表示剩余额度。
4. 校验预设数量、颜色对比、派生规则、旧数据兼容和保存往返；执行前端构建与一次有时限的离线 Rust 检查。
5. 实现完成后由用户退出当前实例，再更新并启动程序；视觉与交互仍由用户确认。

## 实验记录

实现方式：TypeScript 集中定义五个颜色角色及八个预设；React 设置页按深浅分组渲染可选择的卡片，选中状态通过 `aria-pressed` 表达。CSS 变量将五色分别映射到卡片、字段、主要/次要内容和强调元素；边框以背景和正文 22% 通道混色，按钮文字比较黑白对比度后自动选择。Rust JSON 模型新增两个可选迁移字段，读取旧数据时按既有颜色派生后由正常 SQLite 保存写回，不升级数据库表结构。
